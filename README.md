# Car Inventory Analysis Dashboard

## Overview

This project demonstrates the development of an interactive Power BI dashboard for analyzing a car inventory dataset. The report was built using Power BI Desktop and includes data transformation with Power Query, DAX measures, interactive visualizations, and dashboard design best practices.

The dashboard enables users to monitor vehicle inventory, warranty coverage, mileage, vehicle age, and driver assignments through interactive filters.

---

## Objectives

- Import and transform Excel data using Power Query
- Build a clean data model
- Create reusable DAX measures
- Design an interactive dashboard
- Provide actionable insights from vehicle inventory data

---
